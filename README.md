# 🛡️ UPI Safety Assistant

An intelligent Retrieval-Augmented Generation (RAG) based AI assistant designed to help users understand UPI safety, recognize common digital payment risks, and receive grounded safety guidance from trusted sources.

## 🎯 Project Goal

The UPI Safety Assistant combines:

- Retrieval-Augmented Generation (RAG)
- Semantic search
- Hybrid information retrieval
- Document-grounded AI responses
- Source citations
- Scam scenario analysis
- Conversational interaction

The goal is to provide clear, reliable, and explainable information about UPI and digital payment safety.

## 🧠 Core RAG Pipeline

User Query
↓
Query Processing
↓
Hybrid Retrieval
↓
Reranking
↓
Relevant Context
↓
LLM
↓
Grounded Answer + Sources
